# 如何评估 LLM 输出质量

## Question

在生产环境中，如何系统地评估 LLM 的输出质量？

## Answer

### 自动评估

| 方法 | 适用场景 | 工具 |
|------|---------|------|
| 基准测试 | 通用能力 | MMLU、HumanEval、GSM8K |
| LLM-as-Judge | 主观质量 | 用强模型评估弱模型 |
| 字符串匹配 | 结构化输出 | BLEU、ROUGE（局限性大） |
| 自定义评分 | 业务指标 | 针对性评分函数 |

### 人工评估

- **盲评**：评估者不知道哪个输出来自哪个模型
- **A/B 测试**：在线对比用户偏好
- **专家评审**：领域专家评估专业性

### 评估维度

1. **准确性**：事实是否正确
2. **完整性**：是否覆盖了关键点
3. **相关性**：是否切题
4. **安全性**：是否有有害内容 → [[RLHF]]
5. **格式**：是否符合要求的输出格式

### 建立评估流水线

```
开发 → 本地评估（基准 + 自定义） → 灰度（A/B） → 全量 → 持续监控
```

关键：评估集需要随时间更新，避免过拟合固定的评估集。
