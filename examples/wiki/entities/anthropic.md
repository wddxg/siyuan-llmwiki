# Anthropic

Anthropic 成立于 2021 年，由前 OpenAI 研究副总裁 Dario Amodei 和 Daniela Amodei 创立。

## 核心理念

以"Constitutional AI"（宪法 AI）为核心安全框架，强调 AI 系统应该有用、诚实且无害。

## 产品线

- **Claude 系列**：Claude 3.5 Sonnet、Claude 3 Opus、Claude 4 等 → [[GPT-4o vs Claude]]
- **Claude Code**：命令行 AI 编程助手
- **Claude API**：开发者接口，支持 tool use、citations 等高级功能

## 技术特色

1. **Constitutional AI**：用一组"宪法原则"指导 AI 行为，减少对人类标注的依赖
2. **长上下文**：Claude 支持 200K token 的上下文窗口 → [[上下文窗口]]
3. **Tool Use**：原生支持函数调用和 MCP 协议
4. **Computer Use**：Agent 能直接操作电脑界面

## 安全研究

- 发布了多篇关于 AI 对齐、可解释性和安全评估的论文
- 负责任扩展政策（Responsible Scaling Policy）
- 推动了 MCP（Model Context Protocol）开放标准
