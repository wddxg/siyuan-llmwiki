# Mistral AI

Mistral AI 成立于 2023 年，总部位于巴黎，由前 Meta 和 Google DeepMind 研究员创立。

## 核心产品

- **Mistral 系列**：7B、8x7B（Mixtral）、Large 等多规格模型
- **Codestral**：代码专用模型
- **Le Chat**：消费级聊天助手
- **La Plateforme**：企业级 API 服务

## 技术亮点

1. **Mixtral MoE**：混合专家架构，8x7B 参数但推理时只激活 2 个专家
2. **滑窗注意力**：降低长序列的计算成本 → [[Transformer 架构]]
3. **高效推理**：同性能下推理成本远低于 Dense 模型

## 开源策略

Mistral 采用"开源权重 + 闭源 API"的混合模式。核心小模型开源（Apache 2.0），大模型和商业模型闭源。
