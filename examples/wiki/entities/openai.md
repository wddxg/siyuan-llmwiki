# OpenAI

OpenAI 成立于 2015 年，总部位于旧金山，是全球领先的人工智能研究机构和商业公司。

## 核心产品

- **GPT 系列**：从 GPT-1 到 GPT-4o，引领了大语言模型的发展方向 → [[GPT-4o vs Claude]]
- **ChatGPT**：2022 年 11 月发布，两个月内用户突破一亿
- **DALL-E**：文生图模型系列
- **Whisper**：语音识别模型
- **Codex**：代码生成模型，GitHub Copilot 的底层引擎

## 技术路线

OpenAI 坚持 scaling law 路线，通过增大模型参数和数据量来提升能力。核心贡献包括：

1. **RLHF**（人类反馈强化学习）→ [[RLHF]]
2. **InstructGPT**：指令微调范式的开创者
3. **Function Calling**：结构化工具调用接口
4. **Multimodal**：GPT-4V/4o 实现了文本-图像-音频的统一处理

## 商业模式

从非营利组织转型为"封顶利润"结构。通过 API 按 token 计费，同时提供 ChatGPT Plus/Team/Enterprise 订阅。

## 争议与挑战

- 公司治理风波（2023 年 CEO 短暂被解雇事件）
- 安全性与对齐研究的投入比例争议
- 与开源社区的关系紧张 → [[开源 vs 闭源 LLM]]
