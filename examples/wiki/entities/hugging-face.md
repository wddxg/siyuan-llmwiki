# Hugging Face

Hugging Face 从一家聊天机器人公司转型为 AI 开源社区的"GitHub"。

## 核心产品

- **Hub**：托管了 100 万+ 模型和 30 万+ 数据集
- **Transformers**：最流行的预训练模型 Python 库
- **Diffusers**：图像/视频生成模型库
- **Tokenizers**：高性能分词器
- **PEFT / TRL**：参数高效微调和 RLHF 工具

## 对开源 AI 的贡献

Hugging Face 极大降低了开源模型的使用门槛：

1. 统一的模型加载接口（`from_pretrained`）
2. 一键下载和分享模型
3. 社区驱动的模型评估和排行榜
4. Spaces：免费托管 ML 演示应用

## 开源模型生态 → [[开源 vs 闭源 LLM]]

Hugging Face 是开源 LLM 生态的核心基础设施。LLaMA、Mistral、Qwen 等模型都通过 Hub 分发。
