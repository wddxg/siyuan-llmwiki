# LoRA: Low-Rank Adaptation

**作者**: Hu, Shen, Wallis, Allen-Zhu, Li, Wang, Chen
**年份**: 2021
**机构**: Microsoft Research

## 核心思想

预训练模型的权重更新矩阵是低秩的。将 ΔW 分解为两个低秩矩阵：

```
ΔW = BA  (B: d×r, A: r×d, r << d)
```

训练时冻结原始权重 W，只训练 B 和 A。

## 优势

1. **参数高效**：可训练参数减少 10,000 倍以上
2. **显存节省**：不需要存储优化器状态和梯度的完整副本
3. **推理无额外开销**：训练完成后可将 BA 合并回 W
4. **可组合**：多个 LoRA 可以叠加或切换

## 实验结果

GPT-3 175B 上：
- 全量微调：100% 参数
- LoRA (r=4)：0.01% 参数
- 性能差距：几乎为零

## 应用

LoRA 成为开源社区微调 LLM 的标准方案：
- Alpaca、Vicuna 等社区模型都基于 LoRA
- QLoRA = 4-bit 量化 + LoRA，进一步降低显存需求
- Hugging Face PEFT 库提供了标准化实现

## 影响

大幅降低了微调大模型的门槛，推动了开源 LLM 生态的繁荣。
